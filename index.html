Spring Boot live-coding cheat sheet

Generic recipes taken from the assignment patterns (controller → service → repository → DTO → MockMvc). Placeholder names only (Foo, FooDto). Do not paste finished drill answers.

Paging defaults in this project: page 0, size 20, max size 100. Always map entities to DTOs before leaving the service.

1. Endpoint checklist & layer order

Write the contract first (30 seconds): method + path, query/body params, defaults, status codes, response DTO. Then build in this order:

  1. 1. DTO record(s) — never return an entity
  2. 2. Repository method — derived findBy… or @Query
  3. 3. mvn test / context load — broken repo names crash startup
  4. 4. Service interface + impl (@Transactional)
  5. 5. Controller (no business logic)
  6. 6. Endpoint / service test
  7. 7. Commit after each green step
Controllers only wire HTTP. Defaults, caps, filters, and mapping live in the service. Filtering that can be expressed as a query lives in the repository.

2. Generic templates (Foo)

PageDto (exact shape in this project)

public record PageDto<T>(
    List<T> content,
    int page,            // 0-based
    int size,

Controller — GET list with optional filters + paging

@RestController
@RequestMapping("/api/foos")
public class FooController {
  private final FooService fooService;
  public FooController(FooService fooService) { this.fooService = fooService; }

  @GetMapping
  public PageDto<FooSummaryDto> search(
      @RequestParam(required = false) String name,
      @RequestParam(required = false) FooStatus status,
      @RequestParam(required = false) Integer page,
      @RequestParam(required = false) Integer size) {
    return fooService.search(name, status, page, size);
  }
}

@GetMapping("/{id}")
public FooDetailDto findById(@PathVariable("id") Long id) throws NotFoundException {

Controller — POST → 201 + Location

@PostMapping
public ResponseEntity<FooDetailDto> create(
    @Valid @RequestBody FooCreateDto dto) throws ConflictException {
  FooDetailDto created = fooService.create(dto);
  URI location = ServletUriComponentsBuilder.fromCurrentRequest()
      .path("/{id}")
      .buildAndExpand(created.id())
      .toUri();
  return ResponseEntity.created(location).body(created);
}

Service impl — paging defaults + PageDto from Spring Page

@Service
public class FooServiceImpl implements FooService {
  private static final int DEFAULT_PAGE = 0;
  private static final int DEFAULT_SIZE = 20;
  private static final int MAX_SIZE = 100;

  private final FooRepository fooRepository;
  private final FooMapper fooMapper;

  public FooServiceImpl(FooRepository fooRepository, FooMapper fooMapper) {
    this.fooRepository = fooRepository;
    this.fooMapper = fooMapper;
  }

  @Override
  @Transactional(readOnly = true)
  public PageDto<FooSummaryDto> search(
      String name, FooStatus status, Integer page, Integer size) {
    int resolvedPage = page == null ? DEFAULT_PAGE : Math.max(0, page);
    int resolvedSize = size == null
        ? DEFAULT_SIZE
        : Math.min(MAX_SIZE, Math.max(1, size));

    PageRequest pageable = PageRequest.of(
        resolvedPage, resolvedSize, Sort.by(Sort.Direction.ASC, "id"));

    Page<Foo> result = fooRepository.search(name, status, pageable);

    return new PageDto<>(
        result.getContent().stream().map(fooMapper::toSummaryDto).toList(),
        result.getNumber(),
        result.getSize(),
        result.getTotalElements(),
        result.getTotalPages());
  }
}
page = which slice (0-based). size = rows per slice. Spring turns PageRequest into SQL LIMIT/OFFSET/ORDER BY plus a count query. Prefer DB paging over loading everything into memory.

Paging types

Pageable
Interface: page index, size, sort. Pass into repo methods.
PageRequest
PageRequest.of(page, size, Sort.by("id")) — concrete Pageable.
Sort
Sort.by(Sort.Direction.DESC, "startedAt", "id"). Always sort for stable pages.
Page<T>
getContent(), totals. page.map(mapper::toDto) maps items.

@Query JPQL — optional filters, sum, @Param

public interface FooRepository extends JpaRepository<Foo, Long> {

  Page<Foo> findByPlayerIdAndStatus(Long playerId, FooStatus status, Pageable pageable);

  @Query("""
      select f from Foo f
      where (:status is null or f.status = :status)
        and (:name is null or lower(f.name) like lower(concat('%', :name, '%')))
        and (:playerId is null or f.player.id = :playerId)
      """)
  Page<Foo> search(
      @Param("status") FooStatus status,
      @Param("name") String name,
      @Param("playerId") Long playerId,
      Pageable pageable);

  @Query("""
      select coalesce(sum(f.pointChange), 0)
      from Foo f
      where f.player.id = :playerId and f.status = :status
      """)
  int sumPointChangeByPlayerIdAndStatus(
      @Param("playerId") Long playerId,
      @Param("status") FooStatus status);
}
JPQL queries entities and fields (f.player.id), not table/column names. A bad derived method name fails context startup — fix early. Never put page/size as separate repo params; use Pageable.

4. Validation & errors

Bean Validation on DTO records

public record FooCreateDto(
    @NotBlank @Size(max = 100) String name,
    @NotBlank @Email @Size(max = 255) String email,
    @NotNull @Min(0) Integer score,
    @NotNull @Max(100) Integer percent,
    @Positive Long relatedId,
    @Past Instant bornAt) {}

Trigger with @Valid @RequestBody on the controller parameter. Common annotations: @NotNull, @NotBlank, @Size, @Min, @Max, @Email, @Positive, @Past.

Exception → status (from GlobalExceptionHandler)

ExceptionHTTPNotes
ConflictException409 ConflictDuplicate / state clash
NotFoundException404 Not FoundMissing resource
ValidationException422 Unprocessable ContentBusiness rules; includes errors list
MethodArgumentNotValidException422Bean Validation on body failed
HttpMessageNotReadableException400 Bad RequestBroken JSON
MethodArgumentTypeMismatchException400e.g. ?status=FOO not an enum
ErrorResponseExceptionpassthroughUses its own status code
RuntimeException (catch-all)500Logged; generic message

How to throw

throw new NotFoundException("No foo with id " + id + " exists");
throw new ConflictException("Email already registered");
throw new ValidationException("Invalid placement", List.of("square: out of bounds"));

// orElseThrow style
Foo foo = fooRepository.findById(id)
    .orElseThrow(() -> new NotFoundException("No foo with id " + id + " exists"));
Rule of thumb: malformed → 400, well-formed but invalid → 422, conflict with current state → 409, missing → 404. Controllers declare throws; the advice maps them.

5. Test templates

Imports match this project's Boot 4 / tools.jackson stack. Profile test uses in-memory H2; @Transactional rolls back after each test.

Endpoint test (MockMvc)

import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.webmvc.test.autoconfigure.AutoConfigureMockMvc;
import org.springframework.http.MediaType;
import org.springframework.test.context.ActiveProfiles;
import org.springframework.test.web.servlet.MockMvc;
import org.springframework.transaction.annotation.Transactional;
import tools.jackson.databind.ObjectMapper;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.header;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

@SpringBootTest
@AutoConfigureMockMvc
@ActiveProfiles("test")
@Transactional
class FooEndpointTest {

  @Autowired private MockMvc mvc;
  @Autowired private ObjectMapper objectMapper;

  @Test
  void searchFiltersAndPages() throws Exception {
    mvc.perform(post("/api/foos")
            .contentType(MediaType.APPLICATION_JSON)
            .content("""
                {"name":"Alpha","email":"a@example.com"}
                """))
        .andExpect(status().isCreated())
        .andExpect(header().exists("Location"));

    mvc.perform(get("/api/foos")
            .param("name", "Alpha")
            .param("size", "500"))
        .andExpect(status().isOk())
        .andExpect(jsonPath("$.content.length()").value(1))
        .andExpect(jsonPath("$.size").value(100))
        .andExpect(jsonPath("$.content[0].secret").doesNotExist());

    mvc.perform(get("/api/foos").param("status", "NOT_AN_ENUM"))
        .andExpect(status().isBadRequest());
  }
}

Service test (AssertJ)

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

@SpringBootTest
@ActiveProfiles("test")
@Transactional
class FooServiceTest {

  @Autowired private FooService fooService;

  @Test
  void findByIdThrowsWhenMissing() {
    assertThatThrownBy(() -> fooService.findById(999_999L))
        .isInstanceOf(NotFoundException.class);
  }
}

7. Run tests & try the API

Run everything from backend/. It needs JDK 26 and Maven; on Fedora, install Maven with sudo dnf install maven (or use IntelliJ's Maven tool window). There's no auth, so plain curl calls work straight away.

Run the tests

cd backend
mvn -version                                   # must say Java 26
mvn test                                       # all tests (in-memory H2, profile "test")
mvn test -Dtest=GameEndpointTest               # one class
mvn test -Dtest=GameEndpointTest#startPlaceHintSubmitSurrenderRoundTrip   # one method
mvn clean package                              # compile + test + build the JAR

In IntelliJ, right-click src/test/java and choose Run 'All Tests', or press Ctrl+Shift+F10 inside a test.

Start the backend (terminal 1)

cd backend
mvn spring-boot:run                                         # http://localhost:8080, API under /api
mvn spring-boot:run -Dspring-boot.run.profiles=datagen      # same, with example data
# stop: Ctrl+C · logs: logs/blackboxchess.log · DB file: data/ (delete data/ to reset)

Try it with curl (terminal 2)

B=http://localhost:8080/api

# 1. create a player   -> 201 + Location: /api/players/1
curl -i -X POST $B/players -H 'Content-Type: application/json' \
  -d '{"firstName":"Max","lastName":"Muster","email":"max@example.org"}'

# 2. import a puzzle   -> 201
curl -X POST $B/puzzles -H 'Content-Type: application/json' \
  -d '{"boardSize":4,"solution":{"A4":"KING","C2":"ROOK"}}'

# 3. create a scoring config (the first one becomes active) -> 201
curl -X POST $B/scoring-configs -H 'Content-Type: application/json' \
  -d '{"name":"demo","initialPuzzleScore":100,"hintCost":3,"wrongSubmissionCost":7,"solveBonus":0,"lossPenalty":0}'
curl $B/scoring-configs/active

# 4. start a game      -> 201 + Location: /api/games/1
curl -i -X POST $B/games -H 'Content-Type: application/json' -d '{"playerId":1,"puzzleId":1}'

# 5. play it
curl -X PUT  $B/games/1/placements -H 'Content-Type: application/json' -d '{"piece":"KING","square":"A4"}'
curl -X POST $B/games/1/hints      -H 'Content-Type: application/json' -d '{"square":"B3"}'
curl -X PUT  $B/games/1/placements -H 'Content-Type: application/json' -d '{"piece":"ROOK","square":"C2"}'
curl -X POST $B/games/1/submissions
curl -X POST $B/games/1/surrenders

# 6. read things
curl "$B/players?page=0&size=5"
curl "$B/players/1/games?status=FINISHED"
curl $B/players/1/statistics
curl $B/rankings

Provoke the error statuses

curl -s -o /dev/null -w '%{http_code}\n' $B/players/999                 # 404 NotFound
curl -w '\n%{http_code}\n' "$B/players/1/games?status=FOO"               # 400 type mismatch
curl -w '\n%{http_code}\n' -X POST $B/players -H 'Content-Type: application/json' \
  -d '{"firstName":"","lastName":"X","email":"nope"}'                    # 422 @Valid
curl -w '\n%{http_code}\n' -X POST $B/games/1/submissions                # 422 if pieces are missing

Tips: add -i to see the status and headers (for example Location), and pipe into | jq for pretty JSON. Every log line for one request shares the same [requestId].
